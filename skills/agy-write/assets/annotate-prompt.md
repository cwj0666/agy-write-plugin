# 작업 개요

대상 파일 이름: {{path}}
작업 위치: {{location}}
요청 사항: {{request}}

작업 위치가 비어 있으면 파일 전체를 대상으로 작업합니다.
요청 사항이 비어 있으면 필요한 위치에 주석과 docstring을 작성하고 기존 글을 정리합니다.

## 수정 대상 및 규칙

- 수정 대상은 주석, docstring, 한글 문자열(LLM 프롬프트, 로그, 안내 문구)이며 문서 파일은 본문입니다.
- 주석, docstring, 한글 문자열 외의 코드는 기계 대조를 거치며 하나라도 바뀌면 원본으로 복원되므로 변경하지 않습니다.
- 코드 옆 주석(`#` 주석, `//` 주석, 줄 끝 주석)은 대상을 가리키는 짧은 명사형 레이블로 작성합니다. "~합니다" 어미와 마침표를 쓰지 않습니다. 예: `# 재시도 대기 시간 계산`
- 설명 글(docstring, JSDoc 설명 문단, 파일 머리 설명)은 "~합니다" 문장으로 작성하고 마침표로 끝냅니다. 예: `"""변경 파일 목록을 반환합니다."""`
- JSDoc의 `@param` 및 `@returns` 설명은 명사구로 작성합니다.
- Python 파일은 작업 범위 안의 모듈, 클래스, 함수에 docstring을 작성합니다. JS 계열 파일은 작업 범위 안의 최상위 함수마다 JSDoc을 작성합니다. 작업 범위는 작업 위치를 기본으로 하되 요청에 범위가 명시되어 있으면 해당 범위를 따릅니다. 코드 옆 주석은 모듈 수준 상수 정의 위와 함수 본문의 반복문 및 예외 처리 블록 앞에만 작성합니다. 주석에는 해당 코드가 다루는 대상만 적고 `반복문`, `예외 처리`, `블록` 같은 구문 종류 이름은 붙이지 않습니다. 예: `# 변경 파일 순회`
- 기존 글이 위 규칙에 맞으면 고치지 않고 그대로 유지합니다.
- 주석에 설명 문장, 해석, 경위, 지시형 문구는 작성하지 않습니다.
- 사용자가 지시하거나 금지한 사항을 주석에 되풀이하지 않습니다.
- 한글 문자열 내부의 `{...}`와 `%s` 등 형식 지정자는 변경하지 않고 그대로 유지합니다.
- 사실 관계, 필드 정의, 허용 값 내용은 변경하지 않습니다. 필드나 값을 임의로 추가하거나 삭제하지 않습니다.
- 원본과 요청에 없는 평가 기준, 기대 효과, 목표 수치는 작성하지 않습니다.
- 설정값 변경 방향(엄격, 완화, 증가, 감소)과 효과는 원본이나 요청에 명시된 경우에만 작성합니다.
- 환경 변수, 옵션, 식별자는 원래 이름 그대로 유지하며 한국어 이름을 새로 붙이지 않습니다.
- 요청 표현을 확대 해석하지 않으며 요청에 없는 대상이나 범위를 덧붙이지 않습니다.
- 표 형식을 따르더라도 요청에 값이 없는 칸은 비워 두고 다른 절 값을 가져와 채우지 않습니다.
- 문서 본문은 한국어 "~합니다" 문장을 유지합니다. 단 표의 셀과 목록 항목은 간결한 구 표현을 허용합니다. 괄호 안 보충 구는 명사형으로 끝냅니다. 예: `(권한이 없으면 탭이 노출되지 않음)`
- 긴 하이픈, 이모지, 장식 기호는 사용하지 않습니다.
- 영어 어구를 한글로 단순 음차한 표현이나 단어 단위의 직역 어구는 사용하지 않습니다.
- 통용 외래어 기술 용어, 파일 경로, 명령, 식별자, 콘솔 화면 명칭은 유지합니다. `Python`과 `docstring`처럼 영문으로 쓰는 기술 용어는 음차하거나 번역하지 않습니다.
- 과거 사례, 소요 시간, 경위 등 이력형 서술은 작성하지 않습니다. 현재 유효한 규칙과 방지 대상 목적만 서술합니다.
- 쉼표는 같은 자격의 명사를 3개 이상 나열할 때만 씁니다. 절과 절은 쉼표로 잇지 않고 문장을 나누거나 연결 어미로 잇습니다. 이 기준에 맞는 나열은 `와/과`, `및`, `·`로 바꾸지 않습니다.

## 출력 형식

- 수정한 파일 전체를 코드 블록 표시 없이 출력합니다.
- 파일 출력 직후 다음 줄에 정확히 `=====CHANGES=====`를 출력합니다.
- 구분선 다음 줄부터 위치(줄 범위 또는 함수명)와 함께 변경 항목을 작성합니다.
- 인사말이나 부연 설명은 출력하지 않습니다.
- 대상 파일 내용은 아래에 모두 포함되어 있습니다. 파일 읽기를 포함한 모든 도구를 사용하지 않고 표준 출력으로만 출력합니다.
